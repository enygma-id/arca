# Code of Conduct

ARCA is intended to support serious technical, scientific, and open-source
collaboration.

Participants are expected to:

- communicate respectfully;
- critique ideas and code rather than people;
- disclose material conflicts of interest;
- respect attribution and provenance;
- avoid harassment, discrimination, intimidation, or deliberately disruptive
  behavior;
- treat security and private-data disclosures responsibly.

Project maintainers may moderate participation to protect contributors and the
technical integrity of the project.
