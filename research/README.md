# ARCA Research

ARCA is being developed as research software as well as an engineering tool.

Research questions include:

- what BIM information should survive into a GIS-native representation?
- how should geometric fidelity be measured after generalization?
- when is a compact building-mass representation sufficient?
- what should distinguish LOD1.3 from an enhanced LOD1.3 profile?
- how should IFC georeferencing and user-defined placement be separated?
- how much payload reduction is possible without destroying spatial utility?
- how can a BIM repository publish multiple purpose-specific GIS derivatives?
