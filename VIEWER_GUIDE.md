# ARCA 3D Web Viewer Integration Guide

This guide has been moved to:

👉 **[docs/viewer-guide.md](docs/viewer-guide.md)**

It provides comprehensive instructions and copy-pasteable standalone code examples for visualizing ARCA outputs (LOD 1.3 GeoJSON and full-detail glTF/GLB) with:

- **MapLibre GL JS** (`fill-extrusion` and Three.js custom layer)
- **Deck.gl** (`GeoJsonLayer` and `ScenegraphLayer`)
- **CesiumJS** (3D globe polygons and ENU `Model.fromGltfAsync`)
