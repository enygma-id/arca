# Licensing Model

```text
ARCA
├── Community Edition
│   └── AGPL-3.0-only
└── Enterprise Edition
    └── Separate commercial license
```

## Community Edition

The canonical public Community Edition is licensed under `AGPL-3.0-only`.

The complete license text is in the repository root [`LICENSE`](../LICENSE).

## Enterprise Edition

Enterprise Edition may be offered separately by Enygma /
PT Enygma Solusi Negeri where sufficient legal rights exist.

See [`../ENTERPRISE.md`](../ENTERPRISE.md).

## Contributor Strategy

To preserve lawful alternative licensing:

- Enygma-owned code should have clear ownership and provenance;
- employee/contractor IP arrangements should be confirmed;
- external contributions should use an auditable CLA process where required;
- third-party code retains its original license;
- incompatible or unclear-provenance code should not enter the canonical repo.

## Third-Party Boundary

Alternative licensing of ARCA-owned code does not relicense third-party
components.

OpenSKP, NumPy, Shapely, Trimesh, GEOS, and any future dependency remain under
their original terms.

## Brand

Open-source copyright permissions do not automatically grant official ARCA or
Enygma project status.
